# Лендинг личной поддержки участника Miata Club

Адаптивный лендинг для личных донатов автору. Автор помогает Miata Club с ремонтом машин и организацией мероприятий, а клуб поддерживает его.

## Структура проекта

```text
public/
  miata_4k.png
src/
  app/
    globals.css
    layout.tsx
    page.tsx
```

Файлы Next.js и TypeScript конфигурации, `package.json` и `.env.local` находятся в корне проекта.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Сбор через Т-Банк

Для локального запуска добавьте в `.env.local` публичную ссылку на сбор, созданный в Т-Банке:

```env
NEXT_PUBLIC_TBANK_FUNDRAISER_URL=https://ссылка-на-сбор
```

Перезапустите `npm run dev`, если меняли переменные окружения. Кнопка открывает страницу сбора как есть; сумму выбирают уже на стороне Т-Банка.

Прогресс на лендинге пока задаётся вручную в `src/app/page.tsx`: обновите `fundraisingRaised`, чтобы отразить текущую сумму сбора. Автоматическая синхронизация потребует отдельного API или другого официального источника данных Т-Банка.

## Публикация на GitHub Pages

Проект настроен на статический экспорт Next.js. GitHub Actions собирает сайт при каждом push в ветку `main` и публикует его по адресу `https://illarioncorp.github.io/donation_landing/`.

1. В настройках репозитория откройте **Settings → Secrets and variables → Actions → Variables → New repository variable** и создайте переменную `TBANK_FUNDRAISER_URL` со своей ссылкой на сбор. Workflow также может прочитать значение с тем же именем из **Secrets**, если оно уже сохранено там.
2. Откройте **Settings → Pages** и выберите источник **GitHub Actions**.
3. Отправьте изменения в ветку `main`. После успешного запуска workflow сайт будет опубликован; ход сборки и публикации виден во вкладке **Actions**.

Значение из `.env.local` существует только на вашем компьютере и не передаётся в GitHub Actions. Добавьте ссылку отдельно в настройки GitHub. Она будет включена в статические файлы публичного сайта — это публичная ссылка на оплату, не секрет или API-ключ. Файл `.env.local` остаётся локальным и исключён из Git.
