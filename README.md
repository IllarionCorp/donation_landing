# Лендинг для донатов

Адаптивный лендинг на Next.js с выбором суммы и периодичности доната, а также необязательным сообщением.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Подключение оплаты

Создайте файл `.env.local` в корне проекта и задайте ссылку на страницу оплаты:

```env
NEXT_PUBLIC_DONATION_URL=https://example.com/pay
```

Лендинг добавляет к ссылке параметры `amount`, `frequency` (`once` или `monthly`) и `message`. Проверьте, что ваш платёжный сервис принимает эти параметры. Без настройки ссылки форма покажет подсказку вместо перенаправления.
